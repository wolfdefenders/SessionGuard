====================================================================
  1. TOOL KO START KARNA (GUI - sab se aasan tareeqa)
====================================================================

    Sirf DOUBLE-CLICK karein:

        SessionGuard.exe

    ...ya phir:

        Run_SessionGuard.bat

    Ya pehle INSTALL_SessionGuard.bat chalayen - wo shortcuts bana
    degi aur Start Menu mein "SessionGuard" add kar degi.

    GUI khul jayega. Ismein:
      - Target URL likhein aur "Start Scan" dabaien
      - Menu: Help > Load Demo Data  (offline demo dekhne ke liye)
      - Menu: Help > Run Self-test   (19 offline checks)

    GUI ke 7 tabs: Dashboard, Findings, Cookies, Session Tests,
    Entropy, Report, Settings/About.

    Report save karne ke liye: File > Save Report As...

    Scan results ka auto-save folder (EXE ke baghair wajah):
        reports\SessionGuard_Report_<target>_<time>.txt


====================================================================
  2. CMD / COMMAND PROMPT SE USE KARNA (commands)
====================================================================

    Windows Start menu > "cmd" kholen, phir apne folder mein jayen:

        cd C:\Users\%USERNAME%\Downloads\SessionGuard
        (apna asli path likhein jahan aapne ZIP extract ki hai)

    a) GUI kholna (koi scan nahi):
        SessionGuard.exe

    b) GUI + pehle se loaded demo data:
        SessionGuard.exe --demo

    c) Command-line scan (bundled lab server example):
        SessionGuard.exe http://127.0.0.1:5057/ --login-url /login
            --username testuser --password TestPass123

    d) Apni kisi LOCAL test site ka scan (sirf apne lab sites par):
        SessionGuard.exe http://localhost:8080/ --cookie-names sessionid

    e) Offline self-test:
        SessionGuard.exe --selftest

    NOTE (important): SessionGuard.exe ek "windowed" build hai, is
    liye cmd window mein scan ka text nahi chapega. Scan chupke se
    chalta hai; mukammal hone par ek POPUP aata hai jo report ka
    path batata hai, aur report file mein sab kuch hota hai:

        reports\SessionGuard_Report_....txt

====================================================================
  3a. TOOL KYA CHECK KARTA HAI (modules)
====================================================================

    1. Target fetch & cookie capture   (login + cookie pakarna)
    2. Cookie flag audit               (Secure / HttpOnly / SameSite)
    3. Entropy & predictability        (Shannon entropy - kamzor
                                        predictable session IDs)
    4. Cookie scope & prefix rules     (__Host- / __Secure- /
                                        Domain/Path scope)
    5. Session rotation test           (login ke baad naya SID?)
    6. Session fixation test           (attacker SID reject hota hai?)
    7. Logout invalidation test        (purana SID logout ke baad
                                        dead hai ya zinda?)
    8. Session ID sampling             (kai SID le kar pattern nikalna)

    Output: Risk score 0-100 (letter grade), severity findings
    (Critical/High/Medium/Low), text report.

        Password : TestPass123

    violation) taake SessionGuard ke findings ki practice ho sake.

    (Developers ke liye: wahi site source se chalani ho to
     Python + flask ke sath:  python lab_server.py 5057)
